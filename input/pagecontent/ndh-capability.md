
The NDH Capability Statements define the required and optional capabilities of the Actors that implement the NDH IG. These statements outline the necessary interactions, resources, and operations that are to be supported to ensure compliance with the NDH specifications.

The NDH Server CapabilityStatement defines query and retrieval of published directory data. The NDH Submission Server CapabilityStatement defines the FHIR API through which update requesters submit new and corrected directory data. A directory that does not accept updates through the FHIR API conforms to the NDH Server CapabilityStatement alone.
